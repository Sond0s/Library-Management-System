# 📚Library Management System 
A Windows form application to apply CRUD Operations to provide easy library management use with all 
system components.

Built with a strong focus on:
1- Clean Architecture
2- Usability and Flexibility
3- Maintainability & Scalability.


## 💻 Technologies:

- C#
- ADO.NET
- SQL Server
- 3-Tier Architecture

## 📝 Features:

### Authentication
- User Login

### Books Management
- View Books
- Add Book
- Update Book
- Delete Book
- Search Books

### Members Management
- Add Member
- Update Member
- Delete Member

### Borrowing Management 
- Borrow Books
- Return Books
- Fine Calculation

### Members Fines 
Manage members' fines, payment recording, and preventing any new borrowing process until paying the last fine record.

## ✏Architecture

Presentation Layer (WinForms)
↓
Business Logic Layer (BLL)
↓
Data Access Layer (DAL)
↓
SQL Server Database
